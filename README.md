# jiayizhang-k.github.io

Personal academic website of Jiayi Zhang.

## Before uploading
1. Add your photo as `images/profile.jpg` (square crop works best). Until then the sidebar shows a "JZ" monogram.
2. Export your CV from Google Docs (File > Download > PDF) and save it as `files/CV_Jiayi_Zhang.pdf`.

## Publish on GitHub Pages
1. On GitHub, create a new public repository named exactly `jiayizhang-k.github.io`.
2. Click "uploading an existing file" and drag in everything in this folder (`index.html`, `research.html`, `cv.html`, `assets`, `images`, `files`).
3. Commit the changes. After a minute or two the site is live at https://jiayizhang-k.github.io
4. If it doesn't appear, open Settings > Pages and set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.

## Updating
- About (home page, your name tab): edit the paragraphs in `index.html`.
- Research projects: edit the `<article>` blocks in `research.html`.
- CV: replace `files/CV_Jiayi_Zhang.pdf` with a new export.
